## Root vs `obsidian-svelte-ui` README

The top-level `README.md` file also serves as the `README` for the `obsidian-svelte-ui` package. There _may_ be a file at `obsidian-svelte-ui/README.md`; this is actually a build artifact and should not be edited.

If you intend to edit the `README` for the package, edit the `README` at the root of the workspace instead. URLs that reference files within the repo should be relative to that file's location; they are automatically turned into absolute URLs by the preparation script.

The `obsidian-svelte-ui` README is generated by running `obsidian-svelte-ui/scripts/prepare-readme.js`; it is run automatically when preparing the package to be published.
